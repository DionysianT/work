# 外殼日射 ＋ 都市風場 互動模擬

上傳 **EPW 氣象檔**和**量體模型**，在瀏覽器裡調參數、跑：

1. **外殼熱輻射**：建物外殼與地面的期間累積日射量（kWh/m²），色階與 Ladybug 參考圖一致。
2. **都市風場**：簡化 3D 流場（LBM-LES），平面＋鳥瞰，可看風速或風速比。
3. **EPW 分析**：風花圖、各季盛行／次要風向與平均風速（可一鍵套用到風場）、逐月日射與氣溫。

> **免安裝版**：`web/index.html` 是同一套方法的瀏覽器版本，打開網址就能用，見 [web/README.md](web/README.md)。

> 日射可以直接當參考數字用；風場**只適合比較方案**，不能當正式的風環境評估（見 App 內「方法與限制」或 [METHODS.md](METHODS.md)）。

## 安裝與啟動

需要 Python 3.10 以上。

```bash
cd climate-sim
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

瀏覽器會自動開啟 `http://localhost:8501`。

## 使用流程

| 步驟 | 位置 | 說明 |
|---|---|---|
| 1 | 側欄「氣象檔」 | 上傳 `.epw`。沒上傳時日射改用晴空模型（只看相對分布） |
| 2 | 側欄「量體模型」 | 上傳 IFC / OBJ / STL / PLY / GLB；沒上傳則用示範量體 |
| 3 | 側欄「朝上方位角」 | 平面圖 +Y 實際指向的方位，例如朝上是東北 → `45` |
| 4 | 側欄「周邊量體」 | 用表格加方塊（中心 cx, cy、寬 w、深 d、高 h、旋轉 rot），讓風場更接近現況 |
| 5 | 「模型與氣象」分頁 | 確認平面方位正確（+Y = 北），看風花與建議情境 |
| 6 | 「外殼日射」分頁 | 選期間、時段、反射率、網格，按「執行」 |
| 7 | 「都市風場」分頁 | 選 EPW 情境或手動輸入風向風速，調網格、地面邊界、計算域，按「執行」 |

每次執行的風場結果都會保留，可以在「檢視結果」切換比較（例如東風 vs 西風、有無周邊量體）。
結果可下載 PNG（報告用）、CSV（朝向統計）、NPZ（完整數值）。

## 可調參數

**日射**

| 參數 | 預設 | 說明 |
|---|---|---|
| 期間 / 每日時段 | 全年、0–24 時 | 例如只算夏季，或 9–17 時 |
| albedo | 0.2 | 地面反射率（草地 0.2、淺色鋪面 0.3–0.4） |
| 外殼 / 地面網格 | 1.5 / 2.0 m | 越小越細、越慢 |
| 地面範圍 | 外擴 30 m | 0 = 只算建物 |
| 直達計算 | 分區累積 | 「逐時」較精確但慢約 10 倍，兩者差 < 1% |
| 天空分區 | Tregenza 145 | Reinhart 577 較細 |

**風場**

| 參數 | 預設 | 說明 |
|---|---|---|
| 風向 / U10 | 取自 EPW 情境 | 風的「來向」，北=0、東=90；U10 = 10 m 高風速 |
| 地況 α | 郊區 0.25 | 開闊 0.14、市區 0.33 |
| 網格 dx | 3 m | 2 m 更細，但格數約 ×3.4、時間更長 |
| 地面邊界 | free-slip | no-slip 在粗網格下近地風速會偏低約一半 |
| 計算域 | 依建物高度自動 | 上游、下游、兩側、高度 |
| 時間步數 | 自動 | 約 1.5 次流通時間；按鈕上方會即時估算格數、記憶體與時間 |
| Cs / lattice 速度 | 0.17 / 0.055 | 出現「數值發散」時：加大 dx、降低 lattice 速度或提高 Cs |

時間參考：約 50 萬格、3 m 網格的案例，在一般電腦上大約 10–20 分鐘。

## 命令列（批次）

```bash
python cli.py rose --epw TWN_Taipei.epw
```

```bash
python cli.py radiation --epw TWN_Taipei.epw --model model.ifc --up 45 --out out
```

```bash
python cli.py wind --epw TWN_Taipei.epw --model model.ifc --up 45 --season 全年 --rank 1 --out out
```

```bash
python cli.py wind --model model.ifc --up 45 --wd 270 --u10 2.3 --box 120,0,40,40,25 --out out
```

## 模型準備

- 量體要是**封閉實體**；不同量體不要重疊或共用面，否則「點在不在建物內」會判斷錯（地面出現 0 值、風場出現怪洞）。
- OBJ / GLB 若是 Y 軸朝上，勾選「Y 軸朝上的檔案」；單位是 mm 就選 `mm`。
- 自我檢查：無遮蔽屋頂的日射量應接近 EPW 水平面 GHI。
